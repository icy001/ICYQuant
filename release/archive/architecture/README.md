# Architecture Snapshot Archive — ICYQuant GA (v0.4.0-alpha1)

This directory archives the system architecture snapshots captured for the
**ICYQuant v0.4.0-alpha1 GA release**. These artifacts serve as a frozen
reference of the production architecture at the time of General Availability.

## Archival Scope

| Artifact | Description |
|----------|-------------|
| `architecture-overview.md` | High-level system architecture diagram and component map |
| `service-topology.yaml` | Service deployment topology and network relationships |
| `data-flow-diagrams/` | Sequence and data-flow diagrams for key workflows |
| `deployment-topology/` | Kubernetes cluster topology, node layout, and zone strategy |
| `integration-points.md` | External system integration interfaces and protocols |

## Release Context

- **Release:** GA (General Availability)
- **Version:** v0.4.0-alpha1
- **Stage:** GA
- **Status:** stable
- **Archived at:** 2026-07-30

## Usage

These snapshots are intended for:

- Production incident post-mortem reference
- Architecture drift detection in future releases
- Compliance and audit requirements
- Onboarding new team members on the GA architecture baseline
