## 版本概述

ICYQuant v0.4.0-alpha1 是一个重要的里程碑版本，标志着系统核心功能的基本成型。本版本包含了完整的量化交易系统核心模块，包括研究框架、AI 智能决策、回测引擎、订单管理、风险控制、组合管理等关键能力。

### 发布亮点

1. **完整的量化交易系统**: 实现了从研究到交易的完整闭环
2. **AI 智能增强**: 集成大语言模型，提供智能决策支持
3. **高性能回测引擎**: 支持大规模历史数据回测
4. **实时风险控制**: 多维度风险检查和限额管理
5. **云原生架构**: 基于 Kubernetes 的容器化部署
6. **可观测性**: 完整的分布式追踪和监控体系

## 迁移指南

### 从 v0.3.x 升级到 v0.4.0-alpha1

#### 1. API 迁移

**订单 API 迁移**

```python
# 旧版本 (v0.3.x)
response = requests.post("http://api/v0/orders", json=order_data)

# 新版本 (v0.4.0)
response = requests.post("http://api/v1/orders", json=order_data)
```

**组合 API 迁移**

```python
# 旧版本响应格式
{
  "positions": [
    {"symbol": "AAPL", "quantity": 100}
  ]
}

# 新版本响应格式
{
  "positions": [
    {
      "symbol": "AAPL",
      "quantity": 100,
      "avg_cost": 150.25,
      "market_value": 15200.00
    }
  ]
}
```

#### 2. 配置迁移

**风险配置迁移**

```yaml
# 旧版本 (v0.3.x)
limits:
  max_position: 1000000

# 新版本 (v0.4.0)
risk:
  limits:
    max_position_size: 1000000
    max_daily_trades: 1000
```

#### 3. SDK 迁移

```python
# 旧版本 (v0.3.x)
from icyquant import Client
client = Client(api_key="xxx")

# 新版本 (v0.4.0)
from icyquant import Client
client = Client(
    api_key="xxx",
    endpoint="https://api.icyquant.io"
)
```

#### 4. 数据库迁移

```bash
# 执行数据库迁移
alembic upgrade head

# 验证迁移
alembic current
```
