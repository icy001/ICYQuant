# ICYQuant Security Checklist

> 本文档是上线前的安全检查清单。

---

## 1. 认证

- [ ] 所有端点需认证（除健康检查等白名单）
- [ ] 认证端点启用严格限流
- [ ] 密码 / 凭据加密存储
- [ ] 登录失败记录日志并触发安全审计

---

## 2. 授权

- [ ] 所有操作按 RBAC 授权
- [ ] 控制网关切换需高权限 + 四眼审批
- [ ] 职责分离（SoD）已配置
- [ ] 默认拒绝（fail-closed）策略生效

---

## 3. 审计

- [ ] 关键操作进入审计（不可变）
- [ ] 审计记录有保留策略
- [ ] 审计日志纳入备份

---

## 4. 限流

- [ ] API 端点限流已配置
- [ ] 认证端点更严格阈值
- [ ] 超限返回 429

---

## 5. 数据安全

- [ ] 数据库连接加密
- [ ] 敏感配置不写入代码库
- [ ] 日志脱敏（无密码 / Token）
- [ ] 密钥使用密钥管理

---

## 6. 部署安全

- [ ] HTTPS 已启用
- [ ] 容器无敏感信息
- [ ] 最小权限原则（服务账户）
- [ ] 镜像经过扫描

---

## 7. 运行安全

- [ ] 监控告警已配置
- [ ] 备份验证已演练
- [ ] 事故响应流程已就绪
- [ ] Runbook 已更新
