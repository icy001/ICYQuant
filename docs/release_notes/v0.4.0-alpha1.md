# ICYQuant v0.4.0-alpha1 发布说明

## 1. 发布概览

- **版本**: v0.4.0-alpha1
- **发布日期**: 2024-01-15
- **发布类型**: Alpha 预发布版本
- **目标环境**: Dev / Staging
- **稳定性**: 不稳定，不建议生产使用
- **兼容状态**: 部分兼容，存在 Breaking Changes

| 阶段 | 版本 | 预计时间 | 目标 |

## 5. Breaking Changes

### 5.1 影响面

| 影响范围 | 影响程度 | 迁移难度 |
|----------|----------|----------|
| 外部 API 调用方 | 中 | 低 |
| 内部服务依赖 | 高 | 中 |
| 数据库 Schema | 高 | 中 |
| 配置格式 | 中 | 低 |
| 前端代码 | 中 | 低 |

### 5.2 Breaking Changes 详细列表

#### 1. 账户余额 API 响应结构变更

**原格式** (v0.3.x):
```json
{
  "account_id": "ACC_001",
  "balance": 1000000,
  "available": 800000,
  "frozen": 200000
}
```

**新格式** (v0.4.0):
```json
{
  "account_id": "ACC_001",
  "balances": {
    "total": {"amount": 1000000.00},
    "available": {"amount": 800000.00},
    "frozen": {"amount": 200000.00, "breakdown": [...]}
  }
}
```

**迁移建议**:
- 客户端使用 `balances.total.amount` 替代 `balance`
- 新增字段为可选兼容

#### 2. 订单状态枚举扩展

```
v0.3.x 状态枚举:
  PENDING → SUBMITTED → PARTIAL_FILLED → FILLED
                      → CANCELLED → REJECTED

v0.4.0 新增状态:
  PENDING → AI_PROCESSING → SPLITTING → EXECUTING
                          → SUBMITTED → PARTIAL_FILLED → FILLED
                                      → CANCELLED → REJECTED
  新增: AI_RECOMMENDED, SPLIT_COMPLETE, ROUTED
```

#### 3. 数据库 Schema 变更

**新增表**:
```sql
-- AI 策略表
CREATE TABLE ai_strategies (
    id BIGSERIAL PRIMARY KEY,
    strategy_id UUID UNIQUE DEFAULT gen_random_uuid(),

    status VARCHAR(20) DEFAULT 'ACTIVE',

CREATE TABLE ai_predictions (

    strategy_id UUID REFERENCES ai_strategies(strategy_id),

    prediction JSONB,
    confidence DECIMAL(5,4),
    actual_outcome JSONB,
    evaluated BOOLEAN DEFAULT false,
    created_at TIMESTAMPTZ DEFAULT now()

-- 动态风控规则表
CREATE TABLE dynamic_risk_rules (
    id BIGSERIAL PRIMARY KEY,
    rule_id UUID UNIQUE DEFAULT gen_random_uuid(),

    condition JSONB,
```

## 6. 迁移指南

### 6.1 迁移前提

- 当前版本: v0.3.x (最新稳定版)
- 目标环境: Staging 或 Dev
- 预计耗时: 2-4 小时
- 可并行: 是（新旧版本可共存）

### 6.2 迁移步骤

```bash
#!/bin/bash
# migration-v03-to-v04.sh

set -e

echo "=== ICYQuant v0.3 → v0.4 迁移 ==="

# 步骤 1: 准备工作
echo "--- 步骤 1: 准备工作 ---"

# 1.1 备份数据库
kubectl exec -it postgresql-0 -n icyquant-stg -- \
  pg_dumpall -U "$PG_USER" > /backups/pg_v03_backup_$(date +%Y%m%d).sql

# 1.2 代码分支
git checkout release/v0.4.0-alpha1

# 1.3 更新依赖
mvn clean install -DskipTests

# 步骤 2: 数据库迁移
echo "--- 步骤 2: 数据库迁移 ---"

# 2.1 执行 Flyway 迁移
kubectl apply -f - <<'EOF'
apiVersion: batch/v1
kind: Job
metadata:
  name: icyquant-migration-v04
  namespace: icyquant-stg
spec:
  template:
    spec:
      containers:
        - name: migrator
          image: harbor.company.com/icyquant/migrator:0.4.0-alpha1
          command: ["flyway", "migrate", "-target=4.0"]
          env:
            - name: FLYWAY_URL
              value: "jdbc:postgresql://postgresql.default.svc:5432/icyquant"
            - name: FLYWAY_USER
              valueFrom:
                secretKeyRef:
                  name: icyquant-secrets
                  key: db-username
            - name: FLYWAY_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: icyquant-secrets
                  key: db-password
      restartPolicy: Never
EOF

kubectl wait --for=condition=complete job/icyquant-migration-v04 \
  -n icyquant-stg --timeout=15m

# 步骤 3: 配置更新
echo "--- 步骤 3: 配置更新 ---"

# 3.1 更新 ConfigMap
kubectl apply -f configmaps-v04.yaml -n icyquant-stg
```

## 7. 已知问题

### 7.1 严重问题

| 编号 | 问题 | 影响 | 临时解决方案 | 状态 |
|------|------|------|------------|------|
| ISS-001 | AI 模型在高并发下偶发超时 | AI 下单延迟 > 500ms | 增加超时时间到 2s | 修复中 |
| ISS-002 | Rust 交易引擎与 Java 订单服务 gRPC 序列化异常 | 部分订单无法正常路由 | 重启交易引擎 Pod | 修复中 |
| ISS-003 | TimescaleDB 连续查询在大表上性能下降 | 行情历史查询变慢 | 创建物化视图 | 待修复 |

### 7.2 一般问题

| 编号 | 问题 | 影响 | 临时解决方案 | 状态 |
|------|------|------|------------|------|
| ISS-004 | 风控动态限额更新延迟 | 限额调整不及时 | 使用手动限额 | 已知 |
| ISS-005 | Level-3 行情在低流量时段不稳定 | 部分 Level-3 数据缺失 | 降级到 Level-2 | 已知 |
| ISS-006 | AI 置信度计算在极端行情下不准确 | AI 建议不可靠 | 暂停 AI 下单 | 已知 |
| ISS-007 | Istio  sidecar 内存占用偏高 | Pod 内存增加 ~200MB | 调整 sidecar 资源 | 已知 |

### 7.3 已知限制

- **Alpha 版本稳定性**: 不支持生产使用，存在数据丢失风险
- **Broker 兼容性**: 目前仅支持 CTP，恒生支持在 Beta 中提供
- **AI 模型覆盖**: 目前覆盖 3 个主要品种（IC、IF、IH），其他品种将在后续版本支持
- **数据量限制**: AI 预测需要最近 30 天的行情数据，新接入客户需要等数据积累
