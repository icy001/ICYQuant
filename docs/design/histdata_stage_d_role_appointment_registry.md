## 4. 生效与登记规则（v8 §7，回填时适用）

1. **登记位置**：回填 v8 §7 角色表"持有人"列。该列是唯一判据。
2. **未登记后果**：未登记持有人的角色视为尚未指定：其对应规则不生效，且按 §6.6 映射对应的门禁保持 **NOT ASSESSED**；不得以临时安排代替登记。
3. **生效条件（v8 §7"记录位置"第 3 条）**：规则生效需同时满足：① 对应角色持有人已在 **L1**（本文档 §7.x 各子节 + 角色表"持有人"列）登记；② 批准结论已记录于 **L2**（Stage D 自有版本化契约与证据记录）。**L2 载体当前尚未建立**（属 PRE-IMPL 必决），故在 L2 建立前，相关门禁保持 NOT ASSESSED；但此情形**不阻止** §11.4 对"角色持有人已登记"的核验，因为该核验的判据是 L1 的登记状态。

## 5. 变更与撤销（v8 §7）

- 角色的**任命、登记、变更与撤销**必须由项目授权主体作出，并以书面任命记录为准。
- 角色变更或撤销须**重新登记并保留原任命记录**，不得覆盖既有任命记录。
